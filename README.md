### SECTION 4 — H2: The 2026 AI Engineer Skill Stack — What a Course Must Teach

Seven layers. For each: topics, why an AI Engineer needs it, what most Indian courses skip. This doubles as the reader's audit checklist.

- **Layer 1 — Programming & Data Foundations:** Python for AI, NumPy, pandas, SQL, Git/GitHub, environments, APIs, basic software engineering hygiene. Skipped most often for the switchers who need it most.

- **Layer 2 — Maths & Statistics (intuition-first):** linear algebra, gradients, probability, statistics, hypothesis testing. Enough to reason about why models behave as they do.

- **Layer 3 — Core Machine Learning:** regression, classification, trees, ensembles, clustering, feature engineering, cross-validation, bias–variance, regularisation, evaluation metrics, imbalanced data. Still the majority of production AI in Indian companies; commonly taught without evaluation rigour.

- **Layer 4 — Deep Learning & Applied Domains:** neural network fundamentals, optimisers, CNNs, RNNs, transformers and attention, transfer learning, PyTorch, GPU practicalities, NLP (tokenisation, embeddings, NER, sequence models), computer vision basics. You cannot understand LLMs without transformers.

- **Layer 5 — GenAI, LLMs, RAG, LangChain, Fine-Tuning & Agents (the AI Engineer differentiator):** how LLMs work, prompt engineering basic → advanced, LLM APIs, open-weight models and local inference, embeddings and vector databases, RAG basic → production (chunking, hybrid search, re-ranking, evaluation, citations), LangChain/LangGraph/LlamaIndex, fine-tuning (SFT, LoRA/QLoRA, DPO concepts), AI agents (planning, tool use, memory, failure handling), multi-agent frameworks (CrewAI, AutoGen, OpenAI Agents SDK), MCP, multi-modal, LLM evaluation and guardrails. Commonly half-covered: prompting and one API call, then stop.

- **Layer 6 — Production (MLOps & LLMOps):** packaging, FastAPI serving, Docker, CI/CD, experiment tracking, model registry, monitoring and drift, LLM observability, prompt versioning, caching, cost and latency optimisation, cloud deployment. The largest gap between "trained a model" and "hired as an AI Engineer."

- **Layer 7 — Professional & Interview Readiness:** portfolio construction, README quality, AI system design, project defence, technical communication, responsible AI and governance, domain framing.

> **The Seven-Layer Audit:** Take any syllabus PDF — including any on this list — and mark each layer as hands-on, theory-only, or absent. If Layer 5 is only prompting and LangChain basics, or Layer 6 is missing, you are looking at a course that produces demo-makers, not AI Engineers.
